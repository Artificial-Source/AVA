# Support

## Getting help

Start with the documentation map in [`docs/README.md`](docs/README.md), then consult the relevant guides:

- [`docs/core/usage.md`](docs/core/usage.md) for interactive and headless use.
- [`docs/core/configuration.md`](docs/core/configuration.md) and the [environment reference](docs/core/environment-variables.md) for configuration, authentication, models, and local resources.
- [`docs/core/tools.md`](docs/core/tools.md) and [`docs/extensions/lsp.md`](docs/extensions/lsp.md) for model-visible operations and optional language-server support.
- [`docs/operations/troubleshooting.md`](docs/operations/troubleshooting.md) for a symptom-first runbook.
- [`docs/operations/testing.md`](docs/operations/testing.md) for building and testing.
- [`docs/operations/diagnostics.md`](docs/operations/diagnostics.md) for diagnostic and support-export guidance.

For reproducible defects or documentation problems, open a public issue using the appropriate template. Include the AVA revision, Linux distribution/environment, exact command or workflow, expected and actual behavior, and redacted logs. Search existing issues first to avoid duplicates.

## Boundaries

Community support is best-effort. Do not include credentials, tokens, private session data, proprietary source, or exploit details in public reports. Route suspected vulnerabilities according to [`SECURITY.md`](SECURITY.md).

The runtime version is `0.32.0`. This is not a stable release. No release is
scheduled yet, and AVA has no supported released version. Owners will name
supported lines when a release is published. The
[publication policy](docs/operations/publication.md#8-supported-versions)
defines corrections, withdrawal, and support announcements.

For contributions and development setup, see [`CONTRIBUTING.md`](CONTRIBUTING.md).
