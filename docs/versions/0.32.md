# AVA 0.32 ncursesw TUI Replacement

AVA 0.32 is the shippable terminal UI replacement release. The interactive TUI now uses an `ncursesw` foundation for terminal mode, wide-character input, resize/mouse events, and screen drawing while preserving the current backend, provider, session, permission, and non-TTY behavior.

Status: historical baseline. The runtime number was restored to `0.32.0` after the May backend bump. This is not a stable release. The terminal frontend is still in active development. The later backend work remains recorded in `docs/versions/0.60.md`, `docs/versions/0.90.md`, and `docs/versions/1.0.md`. The detailed slice ledger is `docs/versions/0.33.md`.

## Scope

- Require wide-character ncurses (`ncursesw`) as the TUI dependency.
- Enter a `CursesSession` for interactive mode and render frames through `draw_screen(snapshot)`.
- Read interactive keys, wide characters, resize events, and supported mouse events through curses instead of AVA's raw-byte escape parser.
- Remove the obsolete raw terminal guard, ANSI screen guard, raw escape parser APIs, and legacy ANSI full-screen renderer.
- Keep the composer, slash palette, permission dock, transcript, and tool-card semantics from the 0.21 visual refresh.
- Keep non-TTY line shell and automation behavior unchanged.

## Non-Goals

- Do not introduce a fallback to plain `ncurses`.
- Do not change provider, tool, session, permission, or headless protocols as part of the TUI dependency migration.
- Do not add broad theming, plugin UI, or desktop/browser UI scope.

## Milestones

### M1: Build Dependency Foundation

- Document 0.32 as the ncursesw TUI replacement release.
- Detect `ncursesw` during CMake configuration.
- Link `ava_tui` against the detected wide-character curses libraries.
- Fail configuration clearly when wide-character ncurses is unavailable.
- Keep runtime and TUI implementation behavior unchanged.

### M2-M4: Curses Runtime Port

- Introduce the ncursesw terminal abstraction behind the existing TUI boundary.
- Port rendering and input handling incrementally.
- Preserve permission, slash-command, transcript, and composer behavior during the replacement.

### M5: Ship Cleanup

- Delete the obsolete raw terminal / ANSI screen stack.
- Keep `Key` and `InputEvent` as runtime and permission prompt value types.
- Keep `terminal_is_tty()`, terminal signal helpers, UTF-8 backspace behavior, and `CursesSession` in a slim terminal API without exposing curses types publicly.
- Bump the project and runtime version to `0.32.0`.
- Update user documentation to describe the ncursesw-backed TUI and preserve non-TTY fallback guidance.
