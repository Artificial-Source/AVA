# AVA Product Status

These pages describe the current product baseline, principles, release plan,
and evidence. The runtime version is `0.32.0`. This is not a stable release.
The terminal frontend is still in active development. A stable 1.0 release
will follow once it is complete. No release is scheduled yet.

- [Product principles](principles.md): canonical audience, authority, safety, supported-platform, first-release, non-goal, and anti-parity-creep rules.
- [Release readiness](release-readiness.md): current release plan, prerequisites, tooling, and recorded evidence.
- [Features](features.md): current user-facing feature overview.
- [MVP baseline](mvp-baseline.md): current AVA-native product capability baseline; the former parity goal is closed.
- [MVP coverage ledger](mvp-coverage-ledger.md): current capability-to-test/evidence mapping.
- [Backend capabilities at the 1.0 baseline](backend-capabilities-1.0.md): backend status snapshot for the 1.0 capability cut.
